# Children Library Management System - React Frontend

A professional React frontend for the Children Library Management System that connects to your existing Spring Boot backend.

## Features

- **Authentication**: Login/Signup with JWT token-based authentication
- **Role-based Access**: Different permissions for Librarians and Members
- **Books Management**: CRUD operations for books with categories
- **Members Management**: Manage library members
- **Borrow Management**: Track book borrowing and returns
- **Fines Management**: Handle library fines
- **Categories Management**: Organize books by categories
- **Dashboard**: Overview with statistics and recent activities
- **Responsive Design**: Works on desktop, tablet, and mobile devices

## Prerequisites

- Node.js (version 14 or higher)
- npm or yarn
- Your Spring Boot backend running on port 8080

## Installation

1. Navigate to the reactapp directory:
   ```bash
   cd "Children_Library_Management/reactapp"
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm start
   ```

4. Open your browser and go to `http://localhost:3000`

## Backend Connection

The frontend is configured to connect to your Spring Boot backend running on `http://localhost:8080`. The proxy configuration in `package.json` handles API requests automatically.

## Default Users

To test the application, you can create users through the signup form or use any existing users in your backend database.

### User Roles:
- **Librarian**: Full access to all features (CRUD operations)
- **Member**: Limited access (view books, members, etc.)

## API Endpoints Used

The frontend connects to these backend endpoints:

### Authentication
- `POST /api/auth/signin` - User login
- `POST /api/auth/signup` - User registration

### Books
- `GET /api/books` - Get all books
- `POST /api/books` - Create new book (Librarian only)
- `PUT /api/books/{id}` - Update book (Librarian only)
- `DELETE /api/books/{id}` - Delete book (Librarian only)

### Members
- `GET /api/members` - Get all members
- `POST /api/members` - Create new member
- `PUT /api/members/{id}` - Update member
- `DELETE /api/members/{id}` - Delete member

### Borrows
- `GET /api/borrows` - Get all borrow records
- `POST /api/borrows` - Create new borrow record
- `PUT /api/borrows/{id}` - Update borrow record
- `DELETE /api/borrows/{id}` - Delete borrow record

### Fines
- `GET /api/fines` - Get all fines
- `POST /api/fines` - Create new fine (Librarian only)
- `PUT /api/fines/{id}` - Update fine (Librarian only)
- `DELETE /api/fines/{id}` - Delete fine (Librarian only)

### Categories
- `GET /api/book-categories` - Get all categories
- `POST /api/book-categories` - Create new category (Librarian only)
- `PUT /api/book-categories/{id}` - Update category (Librarian only)
- `DELETE /api/book-categories/{id}` - Delete category (Librarian only)

## Building for Production

To create a production build:

```bash
npm run build
```

This creates a `build` folder with optimized production files.

## Troubleshooting

1. **Backend Connection Issues**: Ensure your Spring Boot backend is running on port 8080
2. **CORS Issues**: The backend should allow requests from `http://localhost:3000`
3. **Authentication Issues**: Check that JWT tokens are being properly generated by the backend
